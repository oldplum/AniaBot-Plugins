# RSS订阅

把 RSS/Atom 订阅源绑定到群聊或私聊，机器人后台定时轮询，发现新文章自动推送标题、摘要与链接。支持 RSS 2.0 与 Atom 两种格式，订阅数据持久化保存，机器人重启不丢。

## 功能

- 订阅任意 RSS 2.0 / Atom 源到当前群聊或私聊
- 后台定时轮询（默认 10 分钟），只推送新条目，添加订阅时不会刷屏（历史条目自动设为基线）
- 推送内容含源名、标题、摘要（可配置长度）与原文链接，单次推送条数可配置上限
- 连续拉取失败的源达到阈值后自动移除并在会话中通知，避免无限重试

## 命令

群聊需 **@机器人**，私聊无需 @。

| 命令 | 说明 |
| --- | --- |
| `/rss add <地址>` | 订阅一个 RSS/Atom 源（如 `/rss add https://example.com/feed.xml`） |
| `/rss list` | 查看本会话的订阅列表（含序号） |
| `/rss del <序号>` | 退订指定订阅 |
| `/rss now` | 立即检查一次更新 |
| `/rss` | 查看帮助 |

`rss` 也可写作 `订阅`（如 `/订阅 add ...`）。

## 配置项

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用订阅推送 | true | 关闭后不响应命令且停止后台轮询 |
| 轮询间隔(分钟) | 10 | 检查更新的间隔，最小 5 分钟 |
| 单会话订阅上限 | 10 | 每个群聊/私聊最多可添加的订阅数 |
| 单次推送条数上限 | 5 | 一次检查中每个源最多推送的条目数 |
| 摘要长度 | 100 | 摘要最大字符数，0 为不显示摘要 |
| 失效自动移除阈值 | 20 | 连续拉取失败达到该次数自动移除订阅 |

## 注意事项

- 仅支持 UTF-8 编码的订阅源；个别站点需要 Cookie 或有反爬，会拉取失败（失败次数会在 `/rss list` 中显示）。
- 条目去重依赖源的 guid/link，无法识别的极少数源可能重复推送。
- 每个源单次轮询最多解析 50 条，一次更新超过推送上限时只展示最新若干条，其余以提示代替，不会累积刷屏。
- 所有网络请求仅访问用户填写的订阅地址，不采集任何数据。
