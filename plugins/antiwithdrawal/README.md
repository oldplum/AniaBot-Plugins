# 防撤回

QQ 群聊防撤回插件：在内存中缓存每个群最近 100 条消息，消息被撤回后仍可发送 `/explore`，以「合并转发」形式回顾最近 n 条消息。

## 功能

- 自动缓存每个群最近 100 条消息，撤回前已被缓存的消息之后也能回顾
- `/explore [n]`：把缓存消息打包成合并转发记录发出（n ≤ 100，默认 50）
- 图片/文件链接自动用 NapCat rkey 续期；无法续期且超过 3 分钟时显示「已过期」占位
- 私聊中管理员可远程回顾指定群的缓存消息

## 命令

群聊命令需要先 @机器人，私聊命令直接发送即可。

| 命令 | 场景 | 说明 |
| --- | --- | --- |
| `/explore [n]` | 群聊 | 以合并转发发送最近 n 条缓存消息（n ≤ 100，默认 50） |
| `/explore <群号> [n]` | 私聊（仅管理员） | 查看指定群的最近 n 条缓存消息 |

## 平台限制

防撤回依赖 QQ 专属能力：**合并转发**（把缓存消息打包成聊天记录）与 **rkey**（图片/文件 URL 续期），因此仅在 QQ 平台启用（`plugin.json` 中 `platforms: ["qq"]`）。

## 说明

- 缓存保存在内存中，每群上限 100 条，Bot 重启后清空
- 语音消息回顾时显示 `[语音消息]`；转发消息显示 `[转发消息，暂不支持查看]`
- 图片/文件无法通过 rkey 续期且已超过 3 分钟时，显示过期占位
- 视频消息超过 3 分钟时显示过期占位
- 从插件市场卸载时会主动清空内存中的消息缓存；Bot 退出/重启时缓存随进程释放
- 无配置项，不读写文件，不发起额外网络请求
