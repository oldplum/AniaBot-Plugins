# 视频解析 (videoparse)

群成员发送**抖音 / 快手 / 哔哩哔哩**的视频分享链接，插件自动解析出无水印原视频、下载后发回群里；
也支持 `@机器人 /解析 <链接>` 手动触发，以及私聊使用。

## 功能特性

- **分享链接自动解析**：群里（或私聊）直接发送分享链接即可，无需任何指令。分享文案里夹带的
  统计参数、中文说明、emoji 都能正确剥离，同一视频的多种分享形式（BV 号链接 / b23.tv 短链 /
  带追踪参数的长链接）识别为同一视频。
- **自动去重，不刷屏**：同一会话内 10 分钟内重复出现的同一链接不再解析；同会话两次发送至少间隔
  5 秒；全局最多 3 个链接同时下载。
- **体积与并发保护**：超过配置体积上限的视频直接跳过并提示，避免大文件占满带宽与刷屏。
- **后台解析不阻塞**：解析与下载都在后台协程完成，单条消息事件不会被长时间占用。
- **附带作品信息**：默认在视频前附一行「【平台】标题 - 作者（时长）」，可关闭。
- **失败原因可读**：额度用尽、图集、作品删除、超出体积……都会回一句明确原因，而不是静默失败。

## 支持的链接

| 平台 | 支持的链接形式 |
| --- | --- |
| 抖音 | `https://v.douyin.com/xxxxx/` 短链、`https://www.douyin.com/video/<id>`、`/note/<id>` |
| 快手 | `https://v.kuaishou.com/xxxxx` 短链、`https://www.kuaishou.com/short-video/<id>`、`/fw/photo/<id>` |
| 哔哩哔哩 | `https://www.bilibili.com/video/BV...`、`av<id>`、`https://b23.tv/xxxxx` 短链 |

不支持的链接（用户主页、直播间、其它站点）不会被识别，插件完全不介入这些消息。

## 解析方式与外部服务

插件有两条解析通道，默认**解析接口优先**，失败后 B 站 / 快手会自动改用本地解析（抖音没有本地方案）：

| 通道 | 覆盖平台 | 说明 |
| --- | --- | --- |
| DownCats 解析接口 | 抖音 / 快手 / B站 | 默认调用 `https://www.downcats.com/v1/extract/free/video`（蓝猫素材助手，作者自有的第三方免费接口）。**免费版按 IP 有每日次数上限，超限会提示"额度已用完"**，登录官网可提升额度 |
| 本地解析 | 快手 / B站 | 快手：读取分享页内嵌的作品数据（无水印直链），无需第三方；B站：走官方 `web-interface/view` + `player/playurl` 接口 |

网络请求清单（全部可核对，插件不上报消息内容、不读取凭据）：

1. `www.downcats.com`：抖音解析的唯一途径；快手/B站默认也先走它。
2. 快手短链与分享页（`v.kuaishou.com`、`v.m.chenzhongtech.com`、`www.kuaishou.com`）：本地兜底时抓取。
3. `api.bilibili.com`：本地兜底时取视频信息与地址。
4. 各平台视频 CDN（`*.douyinvod.com`、`*.kwaicdn.com`、`*.kwimgs.com`、`*.bilivideo.com` 等）：
   下载上一步解析出的文件（B 站 CDN 对空 UA 返回 403，故下载统一带浏览器 UA）。

## 指令说明

群聊需要先 @机器人，私聊直接发送：

| 指令 | 说明 | 示例 |
| --- | --- | --- |
| `/解析 <链接>` | 手动解析指定视频链接 | `@Bot /解析 https://v.douyin.com/xxx/` |
| `/parse <链接>` | 同上（英文别名） | `@Bot /parse https://b23.tv/xxxxx` |
| `/视频解析 <链接>` | 同上（中文别名） | `@Bot /视频解析 https://v.kuaishou.com/xxx` |

> 关闭「自动解析」后，插件只响应上述命令，不再处理群里的裸链接。

## 配置项

安装后进入 Web 控制台「配置管理」，在「视频解析」分组中修改：

| 配置键 | 默认值 | 说明 |
| --- | --- | --- |
| `plugin.videoparse.enable` | `true` | 关闭后插件不响应任何链接与命令 |
| `plugin.videoparse.auto_parse` | `true` | 开启后发链接即自动解析；关闭则仅响应 `/解析` 命令 |
| `plugin.videoparse.group_ids` | 空 | 限定生效群（逗号分隔；QQ 填群号，其他平台带前缀如 `tg:-100xxx`）；留空 = 所有群生效 |
| `plugin.videoparse.api_url` | DownCats 接口 | 解析接口地址；填 `off` 关闭接口（抖音将不可用，快手/B站仍可本地解析）。可换成自建服务 |
| `plugin.videoparse.prefer_local` | `false` | B站/快手优先本地解析、把接口额度留给抖音；**群有使用量时建议开启** |
| `plugin.videoparse.max_size_mb` | `200` | 视频体积上限。抖音高清原片常见 100MB 以上，故默认放宽到 200 |
| `plugin.videoparse.send_title` | `true` | 是否在视频前附带「标题 - 作者」信息 |

### 接口额度用尽怎么办

免费接口有每日次数上限（按 IP 计）。三种应对方式：

1. 开启 `prefer_local`：B站/快手走本地解析（准确、无限量），抖音才用接口，显著省额度。
2. 到 DownCats 官网登录账号（登录后不限次数），或把 `api_url` 换成自建解析服务。
3. 抖音链接等次日额度重置后再发；快手/B站不受影响（本地兜底会自动接管）。

## 注意事项

- **下载到本地的临时文件**放在 `data/videoparse/tmp/`，发送后立即删除；超过 2 小时的遗留文件
  会在启动与定时任务中自动清理。卸载插件时会清空该目录。
- **视频会先完整下载再发送**（QQ 等平台发送本地文件更可靠），请合理设置体积上限。
- **抖音高清原片体积较大**（实测可达 150MB+），默认上限 200MB，可按群内需要调整。
- **B 站清晰度**：本地兜底走未登录的 html5 接口，通常为 720P 以内的单文件 mp4。
- **图集不支持**：抖音/快手的多图作品会回复明确提示。
- **平台支持**：需要目标平台支持视频消息段。飞书适配器当前不支持视频段，故未列入
  `plugin.json` 的 `platforms`。

## 常见问题

**Q：为什么抖音必须依赖第三方接口？**
A：抖音网页端播放地址带 `a_bogus` 等随请求生成的签名参数，插件侧无法稳定原生实现。
接口地址做成了配置项，可随时换成自建服务（任何返回
`{"code":"OK","data":{"video":"<直链>","text":"<标题>"}}` 结构的接口都能直接用）。

**Q：为什么视频有时候要等几秒才发出来？**
A：插件是「解析 → 下载 → 发送」，几十 MB 的视频下载需要一点时间；同一时间最多下载 3 个，
排队时会更晚一些。

**Q：会不会被别人拿去刷屏？**
A：同一链接 10 分钟内只解析一次、同会话 5 秒内最多一条、全局并发 3 个下载、超体积上限直接
拒绝；如需更严格限制，可用 `group_ids` 限定群，或关闭 `auto_parse` 改为命令触发。
