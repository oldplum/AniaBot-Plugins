# 提醒事项

在群聊或私聊里设定提醒，到点后机器人主动推送（群聊会 @ 创建者）。支持丰富的中文时间描述与每天/每周循环提醒，数据持久化保存，机器人重启不丢。

## 功能

- 一次性提醒：相对时间（30分钟后、2小时后、3天后）或绝对时间（明天 9点、09-15 10:00、18:00）
- 循环提醒：`每天 8:30`、`每周一 18:00`，到点自动顺延
- 到点推送：群聊 @ 创建者并附内容；私聊直接发送
- 提醒列表与按序号删除；时间省略时刻时默认 09:00

## 命令

群聊需 **@机器人**，私聊无需 @。

| 命令 | 说明 |
| --- | --- |
| `/提醒 <时间> <内容>` | 设定提醒，如 `/提醒 30分钟后 喝水`、`/提醒 每天8:30 早安` |
| `/提醒列表` | 查看本会话进行中的提醒（含序号，按触发时间排序） |
| `/删除提醒 <序号>` | 删除指定提醒 |

### 支持的时间写法

| 写法 | 示例 | 含义 |
| --- | --- | --- |
| N秒/分钟/小时/天/周后 | `45分钟后`、`半小时后` | 相对当前时间 |
| 每天 [时刻] | `每天8:30`、`每天 早安` | 每天循环（省略时刻默认 09:00） |
| 每周X [时刻] | `每周一 18:00` | 每周循环 |
| 今天/明天/后天 [时刻] | `明天 9点 交报告` | 一次性 |
| 周X [时刻] | `周三 18:00 健身` | 下个周X 一次性 |
| 日期 [时刻] | `09-15 10:00`、`2026-12-25 08:00`、`12月25日 8点` | 指定日期一次性 |
| 时刻 | `18:00`、`8点半` | 今天（已过则明天）一次性 |

时刻支持 `8:30` / `8点30` / `8点半` / `8点` 等写法。

## 配置项

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用提醒事项 | true | 关闭后不响应命令且停止到点推送 |
| 检查间隔(秒) | 30 | 到点检查频率，提醒最多延迟该秒数送达 |
| 单会话提醒上限 | 30 | 每个群聊/私聊同时进行的提醒数量上限 |
| 内容长度上限 | 100 | 提醒内容的最大字符数 |

## 注意事项

- 时间按机器人所在服务器的本地时区计算。
- 机器人停机期间错过的循环提醒，恢复后自动顺延到下一个未来时间点，不会补发轰炸；停机超过 400 个周期（约一年）的循环提醒会自动停用。
- 一次性提醒触发后自动删除。
