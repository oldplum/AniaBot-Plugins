# 电子宠物

给每个用户一只专属电子宠物：随机领养（小猫/小狗/小兔/仓鼠/小狐狸/小熊猫/小狮子/小刺猬），喂食、逗宠照顾它长大。饱食度与心情会随时间自然衰减，互动可获得成长值，攒满升级。逗宠还有概率触发随机趣味事件。数据持久化保存，重启不丢。

衰减按「结算时间差」惰性计算，不需要后台定时任务，哪怕几天没照顾，回来一看也能看到正确的衰减结果。

## 命令

群聊需 **@机器人**，私聊无需 @。宠物按**用户**持有（跨群同一只）。

| 命令 | 说明 |
| --- | --- |
| `/领养 <名字>` | 领养一只宠物并取名，如 `/领养 糯米` |
| `/宠物`（别名 `/我的宠物`） | 查看状态卡：等级、饱食度、心情、成长值 |
| `/喂食`（别名 `/喂`） | 喂食，恢复饱食度（太饱了吃不下），有冷却 |
| `/逗宠`（别名 `/玩耍`） | 陪玩，提升心情，有概率触发随机事件，有冷却 |
| `/改名 <新名字>` | 给宠物改名 |
| `/告别 确认` | 送走宠物（需二次确认），之后可重新领养 |

## 配置项

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用电子宠物 | true | 总开关 |
| 喂食恢复饱食度 | 25 | 单次喂食增加的饱食度 |
| 喂食增加心情 | 3 | 单次喂食附带的心情值 |
| 喂食成长值 | 6 | 单次喂食获得的成长值 |
| 逗宠增加心情 | 20 | 单次逗宠增加的心情 |
| 逗宠消耗饱食度 | 3 | 单次逗宠消耗的饱食度 |
| 逗宠成长值 | 8 | 单次逗宠获得的成长值 |
| 饱食度衰减/小时 | 4 | 饱食度每小时自然下降的数值 |
| 心情衰减/小时 | 3 | 心情每小时自然下降的数值 |
| 互动冷却(分钟) | 10 | 喂食/逗宠各自的最短间隔，0 为不限制 |
| 名字长度上限 | 12 | 宠物名最大字符数 |

## 注意事项

- 升级所需成长值随等级递增（60 + 30×(等级-1)）。
- 宠物不会被「养死」：饱食度/心情最低衰减到 0，只会蔫蔫的，不会离开你。
- 长时间不互动也不会丢档，衰减在下次查看时结算。
- 数据保存在持久化存储（命名空间 `pet`），需要框架的 sqlite/mysql 持久化后端才能重启不丢。
