# 签到打卡

每日签到赚积分：随机积分 + 今日运势，连续签到有额外加成，支持积分查询与全服排行榜。数据持久化保存，机器人重启不丢。

积分按**用户**累计（跨群共享），每天（按服务器时区）只能签到一次。

## 命令

群聊需 **@机器人**，私聊无需 @。

| 命令 | 说明 |
| --- | --- |
| `/签到`（别名 `/打卡`） | 每日签到，随机获得积分，连续签到每满 3 天有额外奖励 |
| `/积分`（别名 `/我的积分`） | 查询自己的积分、连签天数、累计天数与当前排名 |
| `/积分排行`（别名 `/积分榜`、`/签到榜`） | 查看全服积分排行榜（默认前 10 名） |

## 配置项

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用签到 | true | 总开关，关闭后不响应任何命令 |
| 单次最少积分 | 10 | 签到随机积分下限 |
| 单次最多积分 | 50 | 签到随机积分上限 |
| 连签奖励系数 | 5 | 连续签到每满 3 天额外 +该值 积分 |
| 连签奖励上限 | 30 | 连签额外奖励的积分上限 |
| 排行榜人数 | 10 | `/积分排行` 展示的人数 |

## 注意事项

- 断签后连签天数重新从 1 计，累计签到天数不受影响。
- 积分为娱乐性质，当前仅用于排行榜展示（后续可与其他插件联动）。
- 数据保存在持久化存储（命名空间 `checkin`），需要框架的 sqlite/mysql 持久化后端才能重启不丢。
