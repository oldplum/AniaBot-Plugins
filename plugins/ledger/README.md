# 群记账本

为每个群聊维护一本**共享账本**（宿舍公费、社团经费、旅行 AA 都适用），私聊里则自动变成**个人账本**。账目按「会话 × 月份」持久化保存，机器人重启不丢；金额以「分」为单位记账，无浮点误差。

## 功能

- 记一笔：支持收入与支出，金额精确到分，事项自由填写
- 月度账单：本月收入、支出、结余、笔数一目了然，末尾附带最近几条
- 流水明细：最近记录带流水号，按流水号可删除
- 权限控制：删除仅限记账本人或管理员；清空本月仅限管理员（私聊即本人）

## 命令

群聊需 **@机器人**，私聊无需 @。

| 命令 | 说明 |
| --- | --- |
| `/记账 <金额> <事项>` | 记支出，如 `/记账 25.5 午饭 加个蛋` |
| `/记账 +<金额> <事项>` | 记收入，如 `/记账 +3000 工资` |
| `/账单` | 本月汇总（收入/支出/结余/笔数 + 最近记录） |
| `/流水` | 最近明细（带流水号与记账人） |
| `/删账 <流水号>` | 删除指定记录（记账本人或管理员） |
| `/清账` | 清空本月账目（管理员），流水号继续顺延 |

## 配置项

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用记账本 | true | 关闭后不响应任何记账命令 |
| 单月记录上限 | 500 | 每个会话每月最多保存的记录条数 |
| 事项长度上限 | 30 | 记账事项的最大字符数 |
| 单笔金额上限(元) | 1000000 | 单笔记账金额的绝对值上限 |
| 流水展示条数 | 10 | `/流水` 展示的最近记录条数 |
| 账单附带明细条数 | 5 | `/账单` 末尾附带的最近记录条数 |

## 注意事项

- 金额支持最多两位小数，非法格式（如 `25.555`）会被拒绝并提示。
- 账本按自然月分册，跨月自动开新册；历史月份的数据保留在存储中。
- 本插件只做记录与统计，不涉及任何转账、支付能力。
